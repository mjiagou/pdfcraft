## 一、 技术本质：为什么你的扫描件只是一张“死图”？

在 **ISO 32000 (PDF 规范)** 中，PDF 可以容纳两类截然不同的内容载体：

```
[ 普通矢量 PDF ]            vs          [ 扫描件 PDF (未OCR) ]
├── 文本算子 (Tj, TJ)                    └── 纯图像字典 (XObject Image)
├── 数学轮廓字体库 (Glyphs)                    • 没有一个真正的文字字符
└── 可被选择、高亮、全文索引                    • 仅由数百万个彩色像素点阵组成
```

很多用户误以为“只要文件后缀是 `.pdf`，里面的字就能复制”。但实际上，无论是复印机扫描生成的 PDF，还是手机拍照生成的 PDF，在文档内部仅仅是一个包裹在容器里的**光栅位图（Raster Bitmap）**。对计算机而言，这只是一张张毫无语义信息的彩色图片。

如果直接使用传统的 PDF 转 Word 工具，往往会因为版面错乱、字体缺失导致排版支离破碎，更无法用于严谨的法律举证或存档。

最佳的行业标准解决方案是：**双层可检索 PDF（Searchable PDF）**。

## 二、 核心解密：双层可检索 PDF（Sandwich PDF）的精密结构

什么是“双层 PDF”？简单来说，它就像一块视觉三明治：

```
┌────────────────────────────────────────────────────────┐
│  顶层：不可见透明文本层 (Text Rendering Mode 3 - 3 Tr)     │  <-- 供鼠标选词、Ctrl+F 搜索、屏幕阅读器朗读
├────────────────────────────────────────────────────────┤
│  底层：原始扫描光栅图像 (Original Scanned Image XObject)  │  <-- 供肉眼查阅，保留100%原件笔迹、红章与纸张质感
└────────────────────────────────────────────────────────┘
```

根据 **ISO 32000-1 第 9.3 节**的文本渲染规则，PDF 规范原生支持一种特殊的文本渲染模式：**Text Rendering Mode 3 (`3 Tr`)**，即“既不填充也不描边，仅建立字符边界与坐标映射的不可见文本模式”。

* **视觉层（底楼）**：肉眼看到的是 100% 原始扫描图片，红色公章、经办人手写签字、纸张微小褶皱原原本本保留，确保法律证据的原始性。
* **检索层（顶楼）**：OCR 引擎识别出每一个字符及其在页面上的绝对坐标边界框（Bounding Box），并在对应位置精准铺上一层不可见文字。
* **用户体验**：当你在 PDF 阅读器中用鼠标划选文字时，你选中的其实是上层的隐形文本；当你按下 `Ctrl+C` 时，复制出来的是标准 Unicode 文本；而在肉眼看来，高亮的光标完全贴合在底层的文字图像上！

## 四、 3步实战指南：零安装、纯本地制作双层可检索 PDF

借助 **TPSH PDF (pdf.tpsh.cc)** 工具箱，整个过程基于编译为 WebAssembly 的本地 AI/OCR 引擎运行，全程无需上传任何服务器，即使拔掉网线亦可顺畅运行。

### 第一步：倾斜纠正与载入（关键预处理）
如果扫描时纸张发生微小倾斜（如旋转了 2°~5°），会严重影响 OCR 文本行的基准线对齐。
1. 若页面明显歪斜，先进入 [PDF倾斜纠正工具](/zh/tools/deskew-pdf)，系统会自动采用霍夫变换（Hough Transform）智能对齐页面水平线。
2. 进入 [PDF OCR文字识别工具](/zh/tools/ocr-pdf)，将扫描文件拖放至上传区域。

### 第二步：选择识别语言与输出模式
1. **语言选择**：勾选文档实际包含的文字种类。如果文档中包含外企合同或技术文档，请同时勾选“简体中文”与“English”。
2. **输出模式**：
   * 选择 **“制作双层可检索 PDF（保持原貌）”**：适合法律合同、官方申报材料、学术文献查阅；
   * 若需二次编辑文字，可配合使用 [PDF转Word工具](/zh/tools/pdf-to-docx) 直接提取为可编辑的 `.docx`。

### 第三步：秒级处理、即刻验证并下载
点击 **“开始 OCR 识别”**。浏览器本地多线程 Worker 将在数秒内逐页完成版面分析与文字图层合成。
* 完成后点击 **“下载 PDF”**。
* **验证效果**：使用任何标准 PDF 阅读器（Chrome、Edge、Acrobat）打开该文件，按下快捷键 `Ctrl+F`（Mac 为 `Cmd+F`），输入关键词，即可看到目标词汇被精准高亮检索，同时可用鼠标随心划选、复制！

## 五、 资深专家避坑答疑（FAQ）

### Q1：制作成双层可检索 PDF 后，文件体积会不会大幅暴增？
**答**：**几乎不会。** 因为顶层的透明文字层只是包含了纯文本流（Content Stream）和对应的字形坐标信息，每页增加的数据量仅约 5KB~15KB。一份 20 页的扫描件生成双层 PDF 后，总体积增加通常不到 200KB。若原本扫描图本身过大，还可在完成后配合使用 [PDF压缩工具](/zh/tools/compress-pdf) 进行微调。

### Q2：扫描件上盖了红色鲜章，会影响印章下方文字的识别吗？
**答**：现代 OCR 预处理算法内置了自适应灰度与色彩分离通道（Color Channel De-mixing）。系统能够有效滤除红色/蓝色印章背景干扰，优先提取深色文字骨架，即使印章刚好盖在签字或条款上，依然能保持 95% 以上的高识别率。

### Q3：手写体签名的识别效果如何？
**答**：印刷体（宋体、黑体、Times New Roman 等）识别率可达 99% 以上；标准行楷手写体可识别大部分常见汉字；但对于极度潦草的艺术签名或草书，OCR 引擎主要定位其边界，建议保持底层原始图像原貌，无需强行替换。

### Q4：如何彻底确认文档没有被上传到第三方服务器？
**答**：按 `F12` 键唤起浏览器“开发者工具（DevTools）”，切换至 **Network（网络）** 标签，勾选 **Offline（离线）**。此时你的电脑处于逻辑断网状态，点击开始 OCR，识别工作依然能够完整高效执行，证明没有任何像素或文字数据离开您的本地设备。
